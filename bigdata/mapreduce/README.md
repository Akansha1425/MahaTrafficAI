# Hadoop MapReduce — Academic Demonstration

## Overview
This module demonstrates the classical **MapReduce** batch processing paradigm (Map -> Shuffle & Sort -> Reduce) applied to historical road traffic accident aggregations.

> ⚠️ **Academic Status:**  
> Labeled as an **Academic Big Data Algorithm Demonstration**.  
> Runs locally via standard Python without requiring a live Hadoop MapReduce daemon or YARN cluster.

## Running the Demonstration
```powershell
.\.venv\Scripts\python.exe bigdata/mapreduce/demonstrate_mapreduce.py
```
