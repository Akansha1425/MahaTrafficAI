# MahaTraffic AI — Frontend Dashboard (Placeholder)

## Overview
This directory is designated for the interactive web dashboard for MahaTraffic AI.

## Planned Technology Stack (Phase 15)
- **Framework:** React 18+ with Vite
- **Language:** TypeScript
- **Styling:** Tailwind CSS & shadcn/ui design components
- **Data Visualization:** Recharts / Plotly for historical accident trends, risk maps, and sentiment charts
- **Routing:** React Router v6
- **API Client:** Axios (consuming `/api/v1/*` endpoints)

## Planned Dashboard Views
1. **Executive Dashboard:** Total historical accident metrics, high-risk location highlights, sentiment balance.
2. **Historical Analytics:** Multi-year accident trends, monthly seasonality distributions, district-level breakdowns, and road classification analyses.
3. **Risk Explorer:** Location search, road type filters, historical risk score gauges, and contributing factors.
4. **Social Signal Explorer:** Public perception signals, complaint topic clustering, and community interaction graphs.
5. **AI Agent Intelligence Chat:** Multi-agent conversation view displaying reasoning traces, tool executions, verified evidence cards, and recommendations.
6. **Reliability & Security Center:** Real-time observability dashboard displaying tool success rate, schema compliance, guardrail interventions, and latency metrics.

> **Note:** Frontend development will commence in **Phase 15** following the completion of data pipelines, ML models, MCP tools, and multi-agent services.
